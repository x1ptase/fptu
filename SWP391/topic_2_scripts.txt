Topic:
Xây dựng công cụ hỗ trợ quản lý yêu cầu và tiến độ dự án phần mềm cho môn SWP391 thông qua Jira và GitHub

A Supporting Tool for Requirements and Project Progress Management in Software Project Course SWP391 Using Jira and GitHub

Context:
Trong đào tạo ngành Kỹ thuật Phần mềm, việc quản lý yêu cầu và theo dõi tiến độ dự án đóng vai trò quan trọng trong việc hình thành tư duy phát triển phần mềm chuyên nghiệp cho sinh viên. 
Hiện nay, Jira thường được sử dụng để quản lý yêu cầu và công việc (tasks), trong khi GitHub được sử dụng để quản lý mã nguồn và quá trình phát triển phần mềm.

Problems:
'Sinh viên gặp khó khăn trong việc tạo các tài liệu và báo cáo cho Giảng viên:
- Tạo tài liệu Đặc tả Yêu cầu Phần mềm (SRS) một cách có hệ thống từ các yêu cầu đã được quản lý trên Jira.
- Tổng hợp báo cáo phân công và thực hiện công việc của các thành viên trong nhóm.
- Tổng hợp báo cáo đánh giá tần suất và chất lượng các lần commit mã nguồn của sinh viên trên GitHub nhằm phản ánh đúng mức độ đóng góp cá nhân.

Primary Actors:
Admin, Lecturer, Team Leader, Team member

Functional Requirements:
'- Admin: manage student groups, manage lecturers, assign lecturers to groups, configure Jira and GitHub integration
- Lecturer: manage students in assigned groups, view requirements and tasks, view project progress reports, view GitHub commit statistics
- Team Leader: manage group requirements and tasks, assign tasks to members, monitor task progress, view team commit summaries
- Team Member: view assigned tasks, update task status, commit source code to GitHub, view personal task and commit statistics
